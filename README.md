## 一、我们收集哪些信息

**本游戏不收集、不使用、不传输任何个人信息。**

具体而言，本游戏：

1. **不要求注册、登录**，没有手机号、密码、昵称、头像等账号信息；
2. **不做实名认证**，不收集姓名、身份证件类型、身份证件号码；
3. **不收集设备信息**，不读取设备标识符（如 IMEI、Android ID、OAID、MAC 地址）、设备型号、操作系统版本；
4. **不收集网络信息**，不收集 IP 地址、访问时间、位置信息，也不能读取您在设备上的其他应用；
5. **不读取您的个人文件**，不访问相册、通讯录、短信、通话记录、日历、剪贴板；
6. **不采集生物特征与多媒体**，不调用相机、麦克风，不采集声音、照片或视频；
7. **不投放广告、不做统计分析、不采集崩溃日志**，没有任何埋点、数据上报行为。

### 在本机保存的数据

为了记录您的训练成绩，本游戏只会把以下内容写入**应用私有目录**（即应用在您设备上的专属存储空间，其他应用无法随意读取）：

| 数据项 | 内容 |
| --- | --- |
| 游戏成绩记录 | 各游戏的游玩次数、最佳成绩与历史成绩 |
| 舒尔特方格统计 | 按维度、模式、异色分类的成绩统计与逐局成绩明细 |
| 运行期临时文件 | 游戏运行过程中产生的日志、缓存等文件（如有） |

这些数据：

- **只存在于您的设备上**，不会离开设备，不会上传到服务器，也不会与任何第三方共享；
- **我们无法访问、无法读取、无法获取**；
- 只有您在游戏内查看统计结果时才会被本机读取。

## 二、我们如何保存您的信息

1. 本游戏的全部数据都存储在您设备上的应用私有目录内，**我们不在任何服务器、数据库或云端保存您的任何信息**；
2. 本游戏不提供云同步，也未开启系统的自动备份功能，数据不会被同步到云端或其他设备；
3. 数据的保存期限由您决定：**卸载本游戏，或在系统设置中清除本游戏的应用数据，即可彻底删除上述全部记录**，删除后无法恢复；
4. 由于数据始终在您的设备上，本政策不涉及个人信息出境、跨境传输等问题。

## 三、设备权限使用情况

**本游戏不申请任何敏感权限。**

本游戏安装包中**未声明网络权限（INTERNET）**，因此本游戏在技术上无法连接网络，无法向任何服务器发送数据。同时，位置、相机、麦克风、通讯录、存储、电话、短信等权限均未申请。

游戏仅使用系统提供的屏幕渲染、触摸输入与音频播放等基础能力，这些能力无需获得权限授权。因此，您在系统设置中不会看到本游戏申请的权限项。

## 四、第三方 SDK 与第三方服务

**本游戏未接入任何第三方 SDK。**

本游戏不包含广告、统计分析、推送、崩溃上报、社交分享、支付等任何第三方组件，不存在任何第三方通过本游戏获取您信息的情形。

## 五、Cookies 及同类技术

本游戏是安装在设备上的原生应用，不是网页应用，**不使用 Cookies、Flash Cookies、本地存储标识符或任何同类跟踪技术**。

## 六、我们如何共享、转让、公开披露您的信息

1. **共享**：本游戏不收集您的信息，因此不会与任何人或第三方共享您的信息；
2. **转让**：我们不会转让您的信息；
3. **公开披露**：本游戏不会公开披露您的信息。

## 七、我们如何保护您的信息

1. 您的数据全部保存在您的设备本地，且位于应用私有目录，其他应用无法随意读取；
2. 由于数据不上传、我们无法访问，不存在因服务器被攻击、泄露而导致您的数据外泄的风险；
3. 请您妥善保管设备本身的安全（如设置锁屏密码、不安装来源不明的应用、不将设备交予不可信的人员使用），这是保护本机数据的有效方式；
4. 请您知悉，任何设备上的本地数据都无法保证绝对安全（例如设备丢失、系统被破解等），这属于您对自有设备的保管风险。

## 八、我们如何处理未成年人的信息

1. 本游戏不收集任何信息，不设账号、不做实名认证、无社交功能、无广告、无付费内容，适合包括未成年人在内的各年龄段用户使用；
2. 如您是未成年人，建议您在监护人的指导下使用本游戏；
3. 如您是未成年人的监护人，您可随时在游戏内查看成绩记录，并通过「清除应用数据」或卸载本游戏的方式，删除设备上保存的全部记录；
4. 由于本游戏不收集任何信息，我们不会持有未成年人的个人信息，也就不存在对未成年人个人信息的处理、存储与删除问题。

## 九、您如何管理您的信息

由于本游戏的数据全部保存在您的设备上，您可以完全自主地管理这些数据，且无需联系我们来处理：

| 您的权利 | 操作方式 |
| --- | --- |
| 访问您的信息 | 在游戏内进入「我的数据」页面，查看各游戏的游玩次数、最佳成绩与历史趋势 |
| 更正您的信息 | 重新游玩对应的游戏即可更新成绩记录；如记录异常，可清除应用数据后重新开始 |
| 删除您的信息 | 在系统设置中清除本游戏的应用数据，或直接卸载本游戏，设备上的全部记录即被彻底删除 |
| 撤回同意 | 本游戏不存在需要长期授权收集的信息；您卸载本游戏即可停止一切本地数据处理 |
| 注销账号 | 本游戏没有账号体系，无需注销 |

## 十、本隐私政策如何更新

1. 本游戏的隐私政策可能会随功能调整而更新，更新后我们会在本页面发布最新版本，并同步更新顶部的「更新日期」；
2. 若本游戏未来新增了需要收集信息的功能（例如联网排行榜、账号登录、广告等），我们会在功能上线前修订本政策，并以显著方式向您提示，在依法取得您的同意后再提供相应功能；
3. 未经您明确同意，我们不会削减您依照本政策所应享有的权利。
